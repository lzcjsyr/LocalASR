# LocalASR

一款基于 whisper.cpp 的 macOS 本地录音转写工具，录音和转写均在本机完成。

它的目标是让会议、访谈和工作讨论等敏感内容不必上传到第三方服务，在保护隐私的同时利用本地算力完成高质量转写。借助 Whisper 系列模型，即使离线使用，也能获得接近主流云端 ASR 服务的效果。

## 核心功能

- 一键录音，实时显示声音波形
- 离线语音转文字
- 转写结果可编辑、复制和保存
- 默认不上传录音或文字；使用 LLM 梳理时只发送转写文字

可选的 LLM 模块支持 OpenAI 兼容接口，用户可以自行配置服务地址、模型、API Key 和润色提示词。

## 适用场景

- 会议纪要、访谈整理、课程和讲座记录
- 播客、视频字幕和内容创作初稿
- 个人语音备忘，以及不方便上传音频的工作流程

## 硬件要求

- macOS 14 或更高版本
- Apple Silicon Mac（M1 或更新）
- 8 GB 内存可运行，16 GB 内存体验更佳
- 可用麦克风和充足的磁盘空间
